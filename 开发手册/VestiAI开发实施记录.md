### 验收结果

执行入口：

```bash
.venv/bin/python -B scripts/check.py
```

该命令在临时目录运行，清除真实凭证配置，并禁止测试连接真实模型服务。

- 原有 27 项测试继续通过，新增备份、恢复、迁移和业务边界检查后共 **38 项测试**。
- 覆盖 SQLite WAL 中已提交数据与图片恢复、不覆盖原数据、损坏备份拒绝恢复、路径越界和符号链接拒绝。
- 模拟迁移中途失败，原数据库表结构、旧记录和版本号保留；升级前备份可以验证。
- 较新数据库被拒绝打开，原有数据不被修改。
- 在没有 HTTP 请求的情况下直接调用业务函数，也不能读取、保存或试穿其他用户的单品；不能借用他人形象照、访问他人任务或绕过 Plus 限制。
- 原有导入、收藏、编辑、去重合并、删除、人物照、试穿记录和旧数据库兼容检查继续通过。
- JavaScript 语法、分页自检、Mac 脚本语法、Gunicorn 配置检查通过。
- ego-browser 本地页面验收：选择连衣裙 → 保存到穿搭库 → 查看已保存单件及图片，流程通过。

本批没有调用真实收费模型，没有验证推荐模型、实际试穿效果或 Mac 安装包构建。页面验收使用临时测试衣橱，未读取真实衣橱或人物照片。

### 操作注意

- 创建完整备份和恢复前，先退出 App 或停止源码服务。SQLite 备份接口保证数据库一致性；图片与数据库的整批一致性要求停服操作。
- 自动备份默认位于实际数据目录的同级 `backups/`，不是固定只在源码目录。App 的备份位于其 Application Support 目录下。
- 恢复不包含 API Key，继续使用原有凭证配置。缩略图和日志由程序重新建立。
- 软件回退需要使用匹配版本的代码和已经核验的备份；不要让旧代码直接写入未来版本数据库。
- 备份与恢复完整命令见 [项目 README](../README.md#备份与恢复)。

## 本地启动修复

状态：**已完成源码服务启动修复与验收**。

页面出现连接被拒绝时，本地端口没有服务监听，原进程已退出；日志没有应用崩溃记录，具体退出原因未确定。原启动脚本在终端前台运行，并在服务就绪前提示成功。本次针对这两个已确认的问题修复启动方式。

- `scripts/macos/server.py` 启动独立后台进程，关闭启动终端后仍可访问；等待健康检查通过后才提示就绪。
- 重复启动会复用已核验的服务；端口被其他程序占用时明确报错。
- 新增 `scripts/macos/stop.command`。停止前核验进程命令、进程编号和服务实例，避免误停其他程序。
- 启动日志位于 `data/server-startup.log`；运行状态可用 `.venv/bin/python scripts/macos/server.py status` 查看。
- 新增两个隔离集成测试，验证启动器退出后继续运行、重复启动、停止服务和端口占用处理。共 **40 项测试**、前端语法、Mac 脚本语法和服务配置检查通过。
- 实际服务在启动器退出后保持运行；ego-browser 中重新加载本地首页成功。

这次修复解决源码网页服务的启动与终端生命周期问题。P0-03、P0-04 涉及的付费任务防重、失败分类和重启恢复仍待开发。
